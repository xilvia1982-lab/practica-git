Trabajo Práctico de PowerShell

Programación para Seguridad Informática

Este trabajo consiste en desarrollar un script en PowerShell para obtener información del sistema.

El script permite consultar:

  • La versión de PowerShell.
  • La permisividad de ejecución.
  • La edición del sistema operativo.
  • La información general de la computadora.
